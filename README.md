# 🍽️ Restaurant Website

A simple and responsive restaurant website created using **HTML and CSS**. This project was developed as a frontend practice project to improve my skills in webpage structure, styling, layout design, and responsive UI development.

##  Project Overview

This website presents a modern restaurant webpage with sections for restaurant information, food items, offers, and other details.

The project focuses on creating a clean and attractive user interface using basic frontend technologies.

##  Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Positioning
* Images and Background Styling

##  Features

* Restaurant homepage
*  Food/food item sections
*  Special offers section
*  Restaurant and food images
*  Responsive and user-friendly layout
*  Custom styling using CSS
*  Navigation and structured content



##  Purpose of the Project

This project was created to practice frontend web development concepts, especially:

* HTML page structure
* CSS styling
* Layout and positioning
* Working with images
* Creating attractive web interfaces
